# Visual direction

Before proposing directions, inspect the product, its category, available
brand/moodboard references, and the user’s anti-references. A palette supplied
by the user or existing brand is authoritative. Otherwise, research
product-appropriate palettes with Color Hunt or comparable current curated
sources when web access is available, record the source URL, and validate the
chosen text/surface pairs. Research to understand the visual territory, then
make an original system rather than a look-alike.

Use an explicit seed. Create **exactly three** candidates; each needs a
different composition, density, geometry, typography, color, imagery, and
motion fingerprint. Minor palette or font variants are not distinct
directions. Select archetypes for the brief, not because they are fashionable.

Gradients are not a default palette. Use at most one restrained supporting
gradient when it reinforces the selected art direction; never use gradients as
the main background, primary CTA treatment, or a substitute for hierarchy.

Each DirectionV1 must include:

- seed, archetypes, and the seven-axis fingerprint;
- palette source, approved colors, spacing, radius, and border rules;
- type pairing and scale;
- desktop and mobile composition studies;
- image direction and asset-provenance plan;
- the user-selected animation technology and reduced-motion fallback;
- conversion structure, rationale, risks, and anti-patterns.

Render a self-contained HTML gallery with desktop/mobile studies. Present it in
chat if the host supports previews, then wait for selection. Do not edit the
product page in this skill.

## Archetype fit

Functional minimalism and bento suit information-heavy SaaS. Warm humanist and
organic suit care-oriented services. Editorial and luxury minimalism suit
high-consideration storytelling. Maximalist, cyberpunk, and kinetic styles are
high-risk tools for a narrow audience, never default solutions. Validate
contrast, readable type, focus treatment, and reduced-motion behavior for all
styles, especially glass, cinematic, neon, and collage directions.

# Original design foundations

Use these principles as a decision aid, not as a visual recipe.

## Hierarchy and conversion

- State the audience-relevant outcome before feature detail.
- Give each section one job and each decision point one clearly primary action.
- Group related information, maintain reading rhythm, and use contrast, scale,
  position, and whitespace together. Color alone cannot carry hierarchy.
- Place proof near the promise it substantiates, but never manufacture proof.

## Type, color, and layout

- Choose type for readable paragraphs first, then give display typography a
  disciplined, repeatable role.
- Use a spacing scale, a responsive grid, and intentional alignment. Empty
  space needs to clarify relationships, not merely signal luxury.
- Validate foreground/background combinations as rendered. Do not rely on
  gradient averages or color perception alone.
- Honor user-provided or brand palettes first. When none exists, research a
  product-appropriate palette from a current curated source such as Color Hunt,
  document the source, and validate the actual application of its colors.
- A gradient is a supporting accent, not a default visual identity: use one
  only when the approved direction needs it and never as a substitute for
  contrast or hierarchy.
- Use trends as expressive tools: a dense collage may suit an event, while a
  care service often benefits from legible calm.

## Inclusive, resilient implementation

- Meet WCAG AA contrast, support keyboard interaction, show focus, use semantic
  structure, and reflow without horizontal scroll at 320px.
- Design narrow layouts independently, reserve image space, use responsive
  images, and test long translations and 200% zoom.
- Make animation optional. Respect reduced-motion preferences and never hide
  essential information behind motion.
